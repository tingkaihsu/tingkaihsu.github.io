Brief Introduction to Conformal Bootstrap

2025-07-12
projects
bootstrap, course

My QFT II course report is a brief introduction to the conformal bootstrap. The initial chapters introduce the fundamental concepts of conformal field theory. We introduce the conformal group using embedding formalism, which provides a clear perspective on quantization. Next, we derive the OPE associativity in Euclidean signature, which serves as a consistent condition in the conformal bootstrap for higher-point correlation functions. Finally, we present some helpful coordinates for the four-point correlator and outline the numerical conformal bootstrap algorithm used to determine the spectrum of consistent theories.
